# 4-Bit Gray to Binary Converter

A 4-bit Gray-to-Binary converter implemented using **behavioral Verilog**.

## Inputs

| Signal | Description           |
| ------ | --------------------- |
| `G`    | 4-bit Gray code input |

## Output

| Signal | Description         |
| ------ | ------------------- |
| `B`    | 4-bit binary output |

The binary bits are generated by successive XOR operations:

```text id="q6zj7n"
B[3] = G[3]
B[2] = B[3] ^ G[2]
B[1] = B[2] ^ G[1]
B[0] = B[1] ^ G[0]
```

## Simulation

The testbench applies valid 4-bit Gray code values and monitors the corresponding binary output.
